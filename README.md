# 発声ログ

スマホのブラウザで毎日5分の発声練習を回し、自動で採点・記録するWebアプリ。

## 鼻声タイプ診断（約2分）
- 抜けチェック：ナ行・マ行のない文を普通に／鼻をつまんで読み、音の差から息の鼻への抜けを見る
- 詰まりチェック：「んー」「まみむめも」を普通に／鼻をつまんで発声し、変化の小ささから鼻の詰まりを見る
- 問診：5問
- 結果を「問題なし・開鼻声・閉鼻声・混合」に分け、タイプに合わせて毎日のメニューを組み直す（30日ごとに再診断を案内）

医療的な診断ではなく、練習の方向を決めるための傾向チェックです。

## 毎日のメニュー
- ロングブレス：吐けた秒数と息の安定度
- あくび喉：タイマー（開鼻声タイプは×2）
- 「カ・ガ」連打：1秒あたりの回数（開鼻声タイプ・滑舌目的で追加）
- 鼻つまみチェック：息の鼻への抜け（閉鼻声タイプはお休み）
- 母音マップ：あいうえおのF1/F2（口の開き・舌の位置）と母音の広がり。声の高さで採点基準を切り替え

記録・診断・設定はブラウザ（localStorage）に保存。記録タブから書き出し・読み込みできます。
音声はすべて端末内で解析し、どこにも送信しません。
